# Invalid ICWire endpoint schema or protocol

ICWire endpoints require the `icwire` compute plugin and a concrete payload
schema supported by that plugin. Candid cannot describe an ICWire function or
actor reference. Keep those references on ICWire routes, or transmit a Principal
and reconstruct its explicitly typed interface at the receiver.

ICWire shared function parameter and result types must match exactly. Positional
payloads do not support Candid structural subtyping or schema evolution.
